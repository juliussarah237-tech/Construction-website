CONSTRUCTION WORLD — WEBSITE PROJECT

TECHNOLOGIES
HTML5 and CSS3 only. No JavaScript, Bootstrap, React, PHP, or other frameworks.

HOW TO OPEN
1. Extract the ZIP.
2. Open the construction-world folder in Visual Studio Code.
3. Open index.html in your browser (or use VS Code Live Server if installed).
4. The navigation connects all six pages.

FOLDER STRUCTURE
construction-world/
  index.html
  about.html
  services.html
  projects.html
  team.html
  contact.html
  css/style.css
  images/  (add downloaded images here)

IMAGES TO DOWNLOAD — SAVE WITH THESE EXACT FILENAMES
- hero-construction.jpg: wide construction site/building photo for page hero backgrounds
- about-construction.jpg: construction site or professionals reviewing a build
- service-residential.jpg: house/residential construction
- service-commercial.jpg: office/commercial building construction
- service-renovation.jpg: renovation or interior finishing
- project-1.jpg, project-2.jpg, project-3.jpg: construction/project photos
- team-member-1.jpg, team-member-2.jpg, team-member-3.jpg: professional portraits

Use images you have permission to use. If you rename a file, update the matching src path in the HTML. Images will appear broken until you add the files.

IMPORTANT PLACEHOLDERS
Company details, statistics, projects, team profiles, testimonials, phone number, email, and address are samples. Replace them with verified information before publishing. Testimonials are explicitly sample testimonials, not genuine reviews.

The contact form is front-end only and does not send or store enquiries. A backend or trusted form service must be connected before real use.

CSS CONCEPTS USED
CSS variables, element/class/ID selectors, Flexbox, CSS Grid, box model, margins/padding, borders, background images and overlays, hover effects, transitions, object-fit, media queries, responsive typography with clamp(), and CSS-only checkbox-based mobile navigation.
